# Release notes

## v1.1 - Feature Update

### New Features
- Added letter grade calculation (A, B, C, D, F).
- Added highest grade calculation.
- Added lowest grade calculation.

### Version Control
- Created two separate feature branches.
- Merged both branches into main.
- Resolved a merge conflict in GradeCalculator.java.
- Preserved both features after conflict resolution.

## v1.0

- Introduced a command-line Java utility to calculate the arithmetic mean of one or more equally weighted grades.
- Accepted decimal grades between 0 and 100 inclusive and displayed the average to two decimal places.
- Returned a clear error for missing, nonnumeric or out-of-range grades.
